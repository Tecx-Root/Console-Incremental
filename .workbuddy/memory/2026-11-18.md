# 2026-11-18 工作日志

## 三项交互修复（HTML 移植版）

1. **资源盒切目录消失**：根因是 `showView()` 的 `beginView()` 会整块替换视图区，而资源盒也在其中。在 `js/terminal.js` 新增独立「常驻区」`term-pinned`（`pinnedEntries` + 独立 DOM 容器，CSS `position:sticky;top:0`），提供 `pinBox()` / `clearPinned()`；`render/repaint` 同时刷新常驻区 live 行，`clear()` 不再移除常驻容器。`main.js` 中 `res_a` 的 `RESOURCE a` / `RESOURCE STATUS` 盒改为 `term.pinBox()`。访问过 `res_a` 后切目录、`cls` 清屏均保留，数值和 Ax6 曲线继续实时刷新，重复进入只保留一个盒子。

2. **玩家名界面 hover 出现滚动条**：根因是 `.flow-suggest { max-height:150px; overflow-y:auto }` 形成嵌套滚动，`.save-chip:hover { transform:translateX(3px) }` 又撑出水平滚动条。去掉建议区高度限制和滚动（改 `overflow:hidden`），hover 改为只变背景/边框/阴影（无位移），`.flow-card` 加 `overflow-x:hidden` 与细滚动条样式。

3. **Ax15 无法关闭**：删除 `main.js` 中 Ax15 的 early-return 特殊分支，改为走通用 `state.auxOn[id] = on`；`Ax_all off` 不再排除 Ax15；`core.js` 的 `AX_LABELS.Ax15` 文案改为「可随时开关」。
