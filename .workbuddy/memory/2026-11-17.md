## 修复 help 无输出（用户反馈）
- 根因：terminal.js 的 normalize() 只处理 string/数组，但 help()/box() 传入单个段对象 {t,c} → r.reduce is not a function 抛错，整个 help 分支中断。
- 修复：normalize() 增加对单个段对象的处理；main.js 命令分发加 try/catch 兜底（出错显示"命令执行出错"而非静默）。
