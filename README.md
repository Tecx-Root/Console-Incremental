# Console Incremental (HTML)

一个控制台风格增量游戏的网页移植版。纯静态项目，双击 `index.html` 即可运行，无需构建、无需服务器、无外部依赖。

## 运行

用浏览器打开 `index.html`，依次输入玩家名、选择存档槽位与小游戏即可进入命令行。输入 `help` 查看命令分类。

## 功能

- 终端式交互：命令历史、Tab 补全、多行输入、实时刷新的目录与资源视图
- 虚拟路径系统：`cd` / `show` / `tree` / 目录别名 / 目录折叠
- 资源增长与购买项：实时速率、增长曲线、峰值统计，价格与可购买状态实时变色
- 大数支持：塔式科学计数法，可显示、计算与存档远超常规浮点范围的数值
- 存档：多存档多槽位、离线进度、导入导出、自动保存；数据保存在浏览器本地
- 辅助功能 Ax1–Ax16：命令补全、倒计时、命令块编辑、曲线面板、交互式文件夹树、购买提醒、自定义命令、分屏、语法高亮、批量执行等
- 配色：四套主题与 16 色前景索引，切换后持久化
- 浮层窗口：滚动新闻、分屏镜像、购买提醒；标题栏可拖动

## 界面

深底终端风格，盒框使用真实 CSS 边框容器（而非文本拼接），配开机自检画面、分步流程卡片与实时状态栏。滚动新闻逐条轮播：一条完全移出屏幕后下一条才进入，条目前无项目符号。适配窄屏，并遵循 `prefers-reduced-motion`。

## 目录

- `index.html` — 入口
- `css/style.css` — 样式与主题变量
- `js/core.js` — 状态、数值、购买项、路径、存档
- `js/terminal.js` — 终端渲染、输入与视图区
- `js/windows.js` — 浮层窗口
- `js/main.js` — 流程、命令分发、游戏循环
- `assets/` — 预留资源目录

## 说明

- 本版本不含背景音乐；输入相关命令会给出提示。
- 存档保存在浏览器 localStorage，清除站点数据会一并清除。
- 全部进度在本地计算，不联网、不需要账号。
