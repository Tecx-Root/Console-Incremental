# Console Incremental (HTML)

由 C++ 控制台增量游戏 `ConsoleIncremental` 移植而来的网页版本。纯静态，双击 `index.html` 即可运行，无需构建或服务器。

**本版本不含背景音乐**：音乐模块、`music` / `vol` 命令与音频资源已整体移除。输入相关命令会给出明确提示；`help` 中的 `c -music` 分类保留，内容标注已移除。

## 已移植功能

- 启动流程：开机自检 → 玩家名输入（按输入内容实时过滤已有存档并显示「存档 xxx / 上次保存：槽位X:…」，点击自动补全）→ 5 槽位选择 → 选小游戏 → 命令行状态块（版本 / Player / Slot / Game1-xri / 教程 / help 提示）
- 虚拟路径系统：`cd` / `~` / `show` / `tree` / 目录名与别名简写 / 快捷跳转（`info`、`atb`、`res_a`、`buff_a`、`upg_a`、`rst_a`、`ach`、`aux`）/ `collapse` 折叠 / Ax3 自动显示规则 / Ax16 叶子目录内容标签
- 资源 `a` 实时增长、增长率公式（乘子 Π + 加数 Σ）、峰值与游玩总时间统计
- 购买项 Ba1-1 / Ba1-2 / Ua1-1 / Ua1-2，R1 显示格式与 Func25 实时配色（可购买价绿、已购编号绿、资源名加粗）
- BigNum 塔式科学计数法（`n e x` / `m e n e x` / `ee x` / `eee x`），`res_a=1e100000`、`res_a=ee 1000` 等大数值可设置、显示与存档
- `help` 六个分类（`c -basic` / `c -save` / `c -action` / `c -music` / `c -others` / `c -dev`）与命令一览逐条对齐；`c -dev` 随 dev 状态变化
- 命令对齐：别名 `rm save` / `rm slot`、`olpg` 用法、`cmd list` / `cmd.add` / `cmd.del` / `cmd.rm` / `cmd.list`（含保留名校验与 16 层递归保护）、`rishow()` / `show()`、`warn -min=N`、`scr.num=N`、`color <0-F>` 前景色索引、`date` / `time` 实时刷新、`exit` / ESC 退出、未知命令两行提示
- Ax1–Ax16 辅助功能：补全、倒计时、命令块编辑（Ax5：选中 / 复制 / 剪切 / 粘贴 / 删除 / 上下移动 / 就地编辑 + Ctrl 快捷键）、Ax6 曲线资源面板、Ax7 可点击可折叠树面板、Ax8/Ax9 提醒降频、Ax10 自定义命令、Ax11 分屏、Ax12/13 高亮加粗、Ax14 操作域、Ax15 批量 `*n`、Ax16 树内容
- 存档：多存档多槽位、加密、导入导出（`export/import save|slot -p "路径"`）、离线进度、三种自动保存（每 30 秒 / 购买后 / 退出或关闭页面时）
- dev 模式：密码校验、标题栏 `(dev mode)`、全部辅助功能解锁、分屏上限 32
- 独立浮层窗口：滚动新闻（逐条轮播，前一条完全移出屏幕后下一条才进入，条目前无分隔符）、分屏镜像、购买提醒（虚拟标题栏可拖动、关闭键无效）
- 输入：SHIFT+ENTER 多行指令（逐行执行）、↑↓ 历史、Tab 补全、Ctrl+Enter 取回选中命令
- 配色：`color <0-F>` 设置前景色索引，`color default|ocean|amber|mono` 切换主题并持久化；底部状态栏实时显示玩家 / 槽位 / 路径 / 资源 / 速度 / 时钟

## 界面

深底终端风格，标签页式终端标题栏、渐变光带与细网格扫描线、开机自检面板、带三步进度指示器的流程卡片、槽位卡片、状态栏胶囊、补全框与浮层窗口。

**所有盒框使用真实 CSS 边框容器**（`help` / 分类帮助 / 资源曲线 / 资源状态 / 文件夹树），不再用 Unicode 框线字符按估算宽度补空格，中英文混排也不会错位。文件夹树的 `├──` / `└──` 是树形连接符，不属于边框。

滚动新闻为单条轮播：同一时刻屏幕上只有一条，完全移出左边界后下一条才从右侧进入，条目前后均不加圆点或菱形分隔符。

适配窄屏并遵循 `prefers-reduced-motion`；CSS 不依赖 `color-mix()`，旧版预览器也能正常显示。

## 启动保障

欢迎页文字常驻可见（不淡出到透明），可通过「进入游戏」按钮、任意键、点击遮罩、定时器或渲染帧看门狗推进；名称 / 槽位 / 小游戏每一步都有可点击按钮，纯鼠标可走完全流程。`index.html` 内含静态启动画面与 `<noscript>` 提示；任何脚本异常显示带「重新加载」按钮的错误面板，不会静默黑屏。

## 运行

用浏览器打开 `index.html`。按提示输入玩家名、选槽位与游戏后进入命令行；输入 `help` 查看命令分类。

## 目录

- `index.html` — 入口
- `css/style.css` — 视觉样式与主题变量
- `js/core.js` — 内核（状态、BigNum、购买项、路径、存档、主题）
- `js/terminal.js` — 模拟终端（历史、视图区、常驻区、live 行、CSS 盒框、Ax5 块编辑、多行输入）
- `js/windows.js` — 浮层窗口（新闻 / 分屏 / 提醒）
- `js/main.js` — 流程、命令分发、目录渲染、游戏循环、状态栏
- `assets/` — 预留资源目录（音频已移除）

## 来源

原 C++ 源码位于相邻目录 `../ConsoleIncremental`（不在本仓库内），移植参考 `main.cpp`、`save_manager.h`、`bignum.cpp`、`console_renderer.cpp`、`news_window.cpp`、`split_window.cpp`、`toast_window.cpp` 及策划案 `doc/Console Incremental策划案.docx`。

## 与原版的差异

- 存档由加密 `.dat` 文件改为浏览器 localStorage（同样加密）；导入/导出落在浏览器本地键 `ci_export_<路径>` 下。
- 多窗口由 Win32 弹窗改为 DOM 浮层，虚拟标题栏保留「关闭键无效、可拖动」的行为。
- 背景音乐按需求整体移除（原版为 Media Foundation 播放器）；`c -music` 仍显示命令一览并标注已移除。
- 盒框由 Unicode 文本边框改为 CSS 边框容器，解决中英文宽度估算导致的对不齐。
- 大数用 `{__bnTower}` 塔式对象表示超出 double 范围的值（数值运算在该量级保持不变），显示规则与 `bignum.cpp::toString()` 一致。
- 目录内容采用「可替换视图区」：切换目录时整块重绘，避免实时行堆积；命令历史保留为滚动日志。
- 资源信息盒位于视图区之外的「常驻区」（`sticky` 贴在终端顶部），访问 `res_a` 后切换目录或 `cls` 清屏都不会消失，数值与曲线仍逐帧刷新；重复进入只重建一个盒子。
- 玩家名界面的存档建议区自然展开，无嵌套滚动条；存档项 hover 只改颜色与阴影，不产生位移。
- Ax15 批量执行与其他辅助开关一致，可随时 `Ax15 on` / `Ax15 off`，`Ax_all off` 也会一并关闭。
