# Console Incremental (HTML)

由 C++ 控制台增量游戏 `ConsoleIncremental` 移植而来的网页版本。纯静态，双击 `index.html` 即可运行，无需构建或服务器。

## 项目状态

- [x] 仓库初始化（.gitignore、基础目录结构）
- [ ] 核心界面与交互移植
- [ ] 资源 / 购买系统
- [ ] 存档系统
- [ ] 音乐与其他功能

## 运行

用浏览器打开 `index.html`。

## 目录

- `index.html` — 入口
- `css/` — 样式
- `js/` — 游戏逻辑
- `assets/` — 音频等资源

## 来源

原 C++ 源码位于相邻目录 `../ConsoleIncremental`（不在本仓库内），移植时以其中的 `main.cpp`、`save_manager.h` 及策划案 `doc/Console Incremental策划案.docx` 为参考。
